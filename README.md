# AcousticReef

### A low-cost bio-acoustic monitoring system for coral reef environments

AcousticReef is a prototype environmental monitoring system designed to
explore underwater acoustic signals associated with coral reef ecosystems.

The system uses underwater sensing and embedded electronics to collect,
process, and record acoustic information from the surrounding environment.

---

## 🌊 Motivation

Coral reef ecosystems produce and interact with a complex underwater
soundscape. Changes in this acoustic environment may provide useful
information about reef activity and ecosystem conditions.

AcousticReef explores whether a low-cost, autonomous sensing platform
can be used to capture and analyse these underwater acoustic signals.

---

## 🎯 Objectives

- Capture underwater acoustic signals
- Process and record environmental sound data
- Develop a low-cost monitoring platform
- Explore patterns in reef acoustic environments
- Create a modular platform for future environmental sensing

## 💻 Software

The firmware is responsible for:

## 📊 Data & Analysis

Collected acoustic data can be analysed for:

- Frequency patterns
- Signal intensity
- Temporal changes
- Repeated acoustic events
- Differences between recording conditions
